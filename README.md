# AfriConnect Summit 2026

Site vitrine pour une conférence tech panafricaine fictive, réalisé dans le cadre de l'examen Web L1.

## Auteur
Oulimata Ba - L1IAGE

## Description
Site responsive de 4 pages présentant AfriConnect Summit, une conférence tech panafricaine annuelle.

## Technologies utilisées
- HTML5 sémantique
- CSS3 (Flexbox, Grid, variables CSS, animations, media queries)
- JavaScript vanilla (DOM, événements, IntersectionObserver, localStorage)
- Google Fonts
- Font Awesome (icônes)
- Git & GitHub

## Fonctionnalités
- Dark mode / Light mode avec persistance (localStorage)
- Navbar dynamique au scroll + menu hamburger responsive
- Animations au scroll (IntersectionObserver)
- Compte à rebours en temps réel
- Compteurs animés
- Onglets du programme (3 jours)
- Filtrage dynamique des intervenants
- Validation de formulaire en JavaScript
- FAQ en accordéon CSS pur
- Bouton retour en haut
